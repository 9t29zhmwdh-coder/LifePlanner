# Roadmap: LifePlanner

## v0.1.0, Initial Release (2026-06-12)
- [x] Text/email/PDF parser for events, tasks, deadlines
- [x] Intelligent event-task linking
- [x] CalDAV sync (local network)
- [x] SQLite FTS5 storage
- [x] AI suggestions via Ollama
- [x] Tauri v2 desktop shell

## v0.2.0, Planned

- [ ] Multiple CalDAV account support

## v0.3.0, Planned

- [ ] Deadline notifications (system tray)

## v1.0.0, Target
- [ ] Windows & Linux support
- [ ] Full test coverage
- [ ] Localization (EN/DE)

## Dual-Licensing Readiness

Assessed 2026-07-11: Community-only, not a Dual-Licensing candidate. LifePlanner is a single-user, offline-by-design desktop life planner (AI extraction from personal emails/PDFs/notes, local CalDAV sync). No team, multi-tenant or enterprise dimension exists anywhere on the roadmap, and the project's core identity (100% offline, no account, no telemetry) is oriented around individual data sovereignty, not shared/organizational use. Revisit only if a genuine team/family shared-calendar use case is scoped in.
